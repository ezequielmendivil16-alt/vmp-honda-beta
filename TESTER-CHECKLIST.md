# VMP-001 Honda Beta · Tester Checklist

Use this quick checklist for every Honda you test.

- [ ] I selected the correct model year.
- [ ] I selected the correct Honda family.
- [ ] I selected the profile that matches engine / transmission / drivetrain.
- [ ] The vehicle summary looks correct.
- [ ] I entered the Maintenance Minder code currently shown by the car, if available.
- [ ] The decoded maintenance tasks make sense compared with the car/owner documentation.
- [ ] I opened at least one Honda source link.
- [ ] The site works correctly on my phone or computer.
- [ ] I recorded anything wrong, missing or confusing in Feedback.
- [ ] I copied or downloaded the feedback report and sent it to the project owner.
